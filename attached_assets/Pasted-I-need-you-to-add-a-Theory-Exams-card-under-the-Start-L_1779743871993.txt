### Step 5: AI Scoring System

When user clicks "Submit and Finish", the system:

1. Sends to AI: (study material + questions + user's answers)
2. AI compares the semantic meaning of each user answer to the correct answer in the study material
3. Scoring logic:
   - Each question = 5 marks maximum
   - Full 5 marks = Answer meaning exactly matches or is semantically equivalent to correct answer
   - Partial marks = Answer is partially correct, missing key points, or has minor inaccuracies (deduct 0.5 to 4.5 marks based on quality)
   - 0 marks = Answer is completely wrong, off-topic, or empty

4. Scoring criteria by answer quality:
   - **Excellent (5/5)** - Complete, accurate, includes all key points
   - **Good (4/5)** - Mostly correct, missing minor points
   - **Satisfactory (3/5)** - Core idea correct but missing important details
   - **Fair (2/5)** - Some relevant information but significant gaps
   - **Poor (1/5)** - Minimal relevant content, mostly incorrect
   - **Very Poor (0/5)** - Completely wrong or empty

5. Calculate total score and percentage: (total_marks_earned / (total_questions * 5)) * 100

### Step 6: Scoring Results Page

After scoring, display:

**Score Summary:**
- Total Score: X/50 (or X/ [questions*5])
- Percentage: XX%
- Time taken
- Message: "Pass" if >=60%, "Needs Improvement" if <60%

**Bottom Button:** "Review Questions"

## Difficulty Level Rules for AI Question Generation

### Easy Mode
Generate questions using these action verbs:
- Define → Give the exact meaning
- List → Mention points only
- Describe → Explain in sequence or detail
- Explain → Give reasons/mechanisms
- Discuss → Give broad explanation with details, advantages, disadvantages, significance
- Compare/Contrast → Show similarities and differences
- Outline → Give summarized organized points
- Enumerate → Mention items one after another
- State
- What is
- Comment on
- Show how
- Explain why
- How many

### Medium Mode
Use these rules randomly across questions:
- Negative/Exception-Based (NOT, EXCEPT, LEAST, FALSE)

- Vague/Qualifier (Usually, Commonly, Rarely, May, Can be)
- Comparative (More likely, Less likely, Most common)
- Causation vs Association (Causes vs Is associated with)

- Partially True, Close Cousin, Opposite Pair, Cause vs Effect Reversal, Mechanism vs Outcome, Gold Standard vs Practical, Overgeneralization, Outdated, Irrelevant but Correct, Extreme Detail, Numerical Near-Miss, Sequence Mix-Up, Eponym Confusion, Population Mismatch, Risk Factor vs Cause, Exception within Exception, Language Framing, Diagnostic vs Therapeutic, Anchor Bias, Too Good to Be True, Single Wrong Word, Unit Trap, Directionality Error, Context Shift, Stage/Phase, Frequency Illusion, Similar Concept, Same Category Overload, Redundant Option, Hidden Clue, Misleading Keyword, Process/Sequence, Feature Swap, Look-Alike Data, Timing Error, Strength of Relationship, Priority/Order, Overlapping Concepts, Terminology Trap, Pattern Recognition
