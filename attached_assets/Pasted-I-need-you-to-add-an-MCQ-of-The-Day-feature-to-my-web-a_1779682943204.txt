Users click "MCQ of The Day" and see TWO card options:
1. **Pre-Clinical Student Card**

- Admin can post TWO separate MCQ sets daily:

- Each set is assigned to a specific date
- Admin can post one set, the other, or both for any given day

### API Endpoints Needed

- GET /api/mcq/today/cards - returns availability for both card types and leaderboard unlock status (whether 8:00 PM has passed)
